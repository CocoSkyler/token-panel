# Token 面板 隐私政策

**更新日期：2026-08-28** ｜ **开发者：CocoSkyler** ｜ 联系邮箱：cocoskylers@gmail.com

Token 面板（以下简称"本应用"）用于在您的设备上展示您本人 AI 编程工具的 Token 用量统计。我们非常重视您的个人信息与隐私保护。本政策说明我们收集哪些信息、如何使用与保护这些信息，以及您所拥有的权利。

## 一、我们收集的信息

1. **华为账号开放标识（openID）**：您使用华为账号登录时，我们仅获取用于识别账号的开放标识字符串，用于隔离与保护您的个人数据。我们不获取您的姓名、手机号、通讯录等敏感个人信息。
2. **AI 工具用量统计数据**：由您自行部署在个人电脑上的采集程序统计并（在您配置后）上报，内容仅为**按日汇总的 Token 数量、来源名称与缓存命中率**，**不包含任何对话内容、提示词、代码内容或模型返回结果**。
3. **推送令牌与卡片标识**：用于向您本人的设备刷新桌面卡片数据，不与任何第三方共享。
4. **基本日志**：为保障服务安全所产生的必要访问日志（时间、请求标识），不用于用户画像。

## 二、信息的使用与存储

- 上述信息仅用于向您本人提供用量展示、云端同步与卡片刷新服务；
- 数据按账号严格隔离存储于境内云服务器（华为云上海区域），传输过程使用 HTTPS 加密；
- 未经您的同意，我们不会向任何第三方提供、公开、出售您的个人信息。

## 三、您的权利

- 您可以随时在设备上删除应用或桌面卡片，停止数据采集与展示；
- 您可以联系上述邮箱，要求**导出或彻底删除**您的全部云端数据，我们将在 7 个工作日内响应；
- 若您不配置电脑端采集程序，本应用不会收集任何用量数据。

## 四、未成年人保护

本应用不面向未成年人提供服务，不会有意收集未成年人的个人信息。

## 五、政策更新

如有重大变更，我们将在本页面更新并标注更新日期。
