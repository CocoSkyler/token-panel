Token面板软件 用户手册

版本 V1.0.0 ｜ 运行环境：HarmonyOS（API 12 及以上） ｜ 开发者：CocoSkyler

一、软件概述

Token面板软件是一款运行于 HarmonyOS 终端的 AI 编程工具 Token 用量统计应用。软件由三部分组成：鸿蒙手机端应用（含 4×4、2×4、2×2 三种桌面服务卡片）、AGC 云函数后端（多用户账号与数据聚合）、以及运行于用户个人电脑的采集器程序（自动统计 GLM/ZCode、Claude Code、Codex CLI 等工具的按日 Token 用量）。

软件主要功能：华为账号一键登录；多来源用量自动发现与聚合；桌面服务卡片实时展示（含近 7 天趋势曲线、各来源占比与缓存命中率）；云端同步与任意网络卡片推送刷新；本地局域网面板模式。

二、运行环境

端要求
手机端HarmonyOS 5 / 7.0 及以上（API 12+），已登录华为账号
电脑端（可选，数据来源）Windows 10+，Python 3.10 及以上，已安装 ZCode / Claude Code / Codex CLI 等工具
网络首次绑定与云端同步需可访问互联网；局域网面板需与电脑同一 Wi-Fi

三、安装与登录

3.1 安装应用

通过应用市场或内测分发链接安装 Token面板应用。安装完成后桌面出现「Token面板」图标。

3.2 华为账号一键登录

打开应用，进入登录页，点击「华为账号一键登录」按钮，在系统弹窗中确认授权。登录成功后应用显示「已登录 · 云同步已开启」，并生成本账号专属的采集器绑定密钥（tp_ 开头）。

四、电脑采集器配置

  1. 在电脑上安装 Python 3.10 及以上版本；
  2. 下载采集器目录（GitHub 仓库 collector/），将 App 中显示的采集器密钥以参数方式传入；
  3. 启动命令示例：
python glm_panel_server.py --cloud-url https://… --cloud-key tp_xxxxxxxxxxxxxxxx

采集器启动后自动扫描本机的 ZCode、Claude Code、Codex CLI 会话记录，按日统计各来源 Token 用量并定时上报云端。上报内容仅包含按日汇总的数量统计，不包含任何对话内容或代码。

五、桌面卡片使用

在手机桌面空白处长按，选择「服务卡片」，找到「Token面板」，可选择三种规格：

规格内容
4×4 完整版今日总消耗、涨跌、预计全天、环形图（今日 vs 7 日均值）、Top2 来源卡片（占比、命中率、迷你趋势线）、近 7 天趋势图（柱状 + 平滑曲线、日均线、峰值标记、今日气泡）
2×4 横幅版今日总消耗、均值对比、各来源行、趋势条
2×2 迷你版今日总消耗与在线状态

点击卡片任意位置可立即刷新；系统每 30 分钟自动刷新一次；登录用户在云端数据更新时由推送通道即时刷新。

六、常见问题

卡片数据不更新？ 请确认电脑采集器正在运行且密钥配置正确；点击卡片可立即刷新。

更换电脑或重装系统？ 在 App 中重新生成采集器密钥并重新配置即可。

统计口径？ Token 总量 = 模型调用输入 + 输出（输入侧包含缓存命中部分），与各工具自身统计一致；命中率为输入缓存复用比例。
